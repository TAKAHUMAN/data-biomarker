# Tepotinib — PMID 33818908

`observations.csv` contains only observed Figure 2b/c tumor-volume means digitized from the paper. It is a semi-quantitative, in-vivo validation dataset; the error bars remain unextracted and replicate-level values are unavailable.

`source_quantitative_summaries.csv` preserves published PK/PD and tumor-growth model estimates separately. Those entries are source results, not experimental observations, and are intentionally excluded from the registry observations table.

`table_1_direct.csv` and `table_2_direct.csv` are exact transcriptions of the main-paper tables. Their modeled/predicted values are intentionally not registered as raw experimental observations.

The raw paper and the Figure 2 image are immutable files under `datasets/raw/`. Supplement parsing is documented by URL because automated download was blocked by the publisher; no unverified response was retained as a raw source artifact.
